# 参与贡献

感谢你愿意改进东方角色提示词生成器。

## 可以贡献什么

- 补充准确、具有视觉区分度的东方角色选项
- 改善提示词的自然语言组织方式
- 修复浏览器兼容性或移动端布局问题
- 改善无障碍体验、交互反馈和文档
- 提交可复现的问题报告

## 提交建议

提交 Issue 时，请说明：

- 使用的浏览器和版本
- 问题发生前的操作步骤
- 实际结果与期望结果
- 如涉及布局问题，可附上截图

新增选项时，请尽量避免仅使用“高级、漂亮、完美”等缺乏明确视觉含义的形容词。选项应该可观察、可组合，并尽量避免与已有内容重复。

## Pull Request

1. Fork 本仓库并创建独立分支。
2. 修改 `index.html`。
3. 在桌面端和移动端至少各测试一次。
4. 确认下拉、多选、自定义输入和实时提示词仍可正常工作。
5. 在 Pull Request 中简要说明修改内容和测试结果。

提交贡献即表示你同意按照本项目的 MIT License 发布相应内容。
